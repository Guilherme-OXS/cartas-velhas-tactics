# Cartas Velhas: Táticas 🃏⚡

Um jogo de cartas e estratégia multiplayer com temática Cyberpunk (e eventos sazonais como Edição de Natal). Desenvolvido para rodar direto no navegador, permitindo partidas online com sistema de cartas táticas e habilidades únicas.

## 🚀 Funcionalidades
- **Multiplayer Online:** Sistema de salas e matchmaking em tempo real.
- **Cartas Táticas:** Uso de cartas como "Bomba", "Escudo", "Motor" e "Trocarte" para dominar o tabuleiro.
- **Sistema de Contas:** Autenticação, histórico de partidas, ranking e lista de amigos.
- **Eventos Temáticos:** Mudança dinâmica de interface e cartas dependendo da época do ano (ex: Evento de Natal).

## 🛠️ Tecnologias Utilizadas
- **Linguagens:** HTML5, CSS3, JavaScript (Vanilla)
- **Backend/BaaS:** Firebase (Firestore, Auth, Storage)
- **Bibliotecas:** Three.js (Renderização) e PeerJS (Conexão WebRTC)
